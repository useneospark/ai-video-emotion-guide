## How to use this library

**Keep performance separate from production.**

Every prompt here contains only visible acting behavior. Room, camera, wardrobe, story, audio, and duration have intentionally been removed.

1. Choose the emotion and intensity.
2. Copy the performance prompt.
3. Add it after your own scene and trigger.
